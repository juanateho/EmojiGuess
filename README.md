# 🤩 EmojiGuess 🧐

## 📝 Descripción del Proyecto

**EmojiGuess** es un divertido y adictivo juego móvil desarrollado en Kotlin para la plataforma Android. El objetivo del juego es simple: adivina tu emoji antes que los demás.

¡Pon a prueba tu capacidad de adivinar o sacar información de cual es tu emoji con los participantes!

## ✨ Características Principales

* **Diseño intuitivo:** Una interfaz de usuario limpia y atractiva diseñada con Android nativo.
* **Sistema de puntuación:** Un sistema para registrar los ganadores y perdedores.

---

## 🛠️ Tecnologías Utilizadas

Este proyecto está desarrollado principalmente para la plataforma **Android** utilizando las siguientes herramientas y lenguajes:

* **Lenguaje de Programación:** [Kotlin](https://kotlinlang.org/)
* **Plataforma:** [Android Studio](https://developer.android.com/studio)
* **Sistema de Compilación:** [Gradle](https://gradle.org/)
* **Backend:** [Firebase](https://firebase.google.com/)

---

## ⚙️ Instalación y Configuración

Sigue estos pasos para obtener una copia local del proyecto y ponerlo en funcionamiento en tu máquina.

### Requisitos Previos

Necesitas tener instalado:

* **Android Studio** (versión más reciente recomendada).
* **JDK** (Java Development Kit) configurado.

### Pasos

1.  **Clona el repositorio:**
    ```bash
    git clone [https://github.com/juanateho/EmojiGuess.git](https://github.com/juanateho/EmojiGuess.git)
    ```

2.  **Abre el proyecto en Android Studio:**
    * Inicia **Android Studio**.
    * Selecciona `Open an existing Android Studio project`.
    * Navega hasta la carpeta `EmojiGuess` que clonaste y selecciónala.

3.  **Sincroniza Gradle:**
    * Android Studio automáticamente intentará sincronizar el proyecto. Si no lo hace, haz clic en el botón **"Sync Project with Gradle Files"** (el icono del elefante con la flecha).

4.  **Ejecuta la aplicación:**
    * Conecta un dispositivo Android físico o utiliza un **Android Virtual Device (AVD)**.
    * Haz clic en el botón **"Run 'app'"** (el icono de triángulo verde) en la barra de herramientas de Android Studio.
